# Talmo

Premium one-page concept for an AI-assisted language learning platform.

Talmo diagnoses a learner's level, goal, pace and blockers, then turns those inputs into a personalized learning path. The page is designed as an investor-ready product narrative with interactive demos, market context and a lightweight business model calculator.

## What's Inside

- Interactive diagnostic demo
- AI tutor chat mock with learning modes
- Knowledge test with instant feedback
- Business model calculator for MRR, ARR, AI cost and model margin
- Profile switcher for different learner segments
- Market data cards with public source links
- Investor one-pager section
- Responsive static implementation with no build step

## Run Locally

```bash
python3 -m http.server 4173
```

Then open:

```text
http://localhost:4173
```

## Notes

Market figures are based on public source summaries and require final verification before use in an official investment deck.
